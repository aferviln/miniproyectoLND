Bienvenido a nuestra web de práctica

Esta página ha sido creada como enunciado y ejemplo para el proyecto de Lenguaje de Marcas que van a realizar. El objetivo es aprender a trabajar con HTML semántico y CSS en un pequeño proyecto web.

El sitio está organizado en cinco páginas: esta página de inicio, las secciones de requisitos, roles y entregables del proyecto, y una página de contacto.

Información del proyecto

  • Asignatura: Lenguaje de Marcas
  • Ciclo: CFGS Administración de Sistemas Informáticos en Red
  • Tecnologías: HTML5 + CSS3
  • Duración: 2 sesiones (6 y 7 de mayo)

Sobre el Proyecto

Como parte de la evaluación práctica los alumnos deberán desarrollar una página web estructurada que demuestre el dominio de los lenguajes de marcas y técnicas de maquetación básica.

Para consultar los requisitos técnicos, los roles específicos o los materiales a entregar pueden navegar a través del menú superior o visitar directamente la página de requisitos del proyecto.

Nota: Aunque el resultado final es relevante, en esta actividad se priorizará la evaluación del proceso de trabajo. Se valorará especialmente la coordinación efectiva entre los miembros del equipo, la correcta distribución de tareas según los roles asignados y el seguimiento de una metodología de desarrollo estructurada.

Trabajo en equipo y roles

El proyecto se realizará en equipos de 3 personas con roles diferenciados para simular un entorno de trabajo real:

Responsable HTML

Encargado de la estructura de las páginas: encabezado, navegación, contenido principal y pie de página. Se asegura de que el código sea semántico y fácil de leer.

Responsable CSS

Se ocupa del diseño visual: colores, tipografías, espaciado, maquetación y pequeños ajustes responsivos para pantallas más estrechas.

Coordinador Visual, Contenido y Documentación

Define la paleta de colores, redacta los textos y prepara la documentación del proyecto, incluyendo capturas y explicación de las decisiones tomadas.
