Requisitos Técnicos

El objetivo de este proyecto es trabajar en equipo con HTML semántico y CSS aplicando estilos y maquetación. El desarrollo del proyecto debe incluir los siguientes requisitos:

  • Debe consistir en una página web temática de cualquier tipo: landing page, e-commerce, blog, portfolio, etc.
  • Pueden usar un layout tradicional o desarrollar uno a medida de su proyecto.
  • Estructura clara de navegación con múltiples ficheros HTML enlazados.
  • Incorporación estilizada de al menos una tabla de datos estructurada.
  • Desarrollo de un formulario con sus campos correctamente etiquetados.
  • Presencia de transiciones CSS suaves en elementos interactivos.
  • Inclusión de animaciones CSS definidas mediante @keyframes.
  • Uso de una paleta de colores que cumpla los estándares de contraste WCAG para asegurar la accesibilidad.
  • Implementación de diseño responsivo (media queries) para una visualización óptima en móviles y tablets.
  • Optimización de recursos visuales para garantizar una velocidad de carga eficiente.
  • Se valorará positivamente el uso de herramientas de control de versiones (GitHub, Codeberg) y herramientas de colaboración en línea (como Google Docs).
