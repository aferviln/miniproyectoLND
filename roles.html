Distribución de Responsabilidades

Para simular un entorno profesional el trabajo se divide en tres roles clave. A continuación se detallan las tareas específicas de cada uno:

Responsable HTML

  • Definición de la estructura de las páginas.
  • Implementación de etiquetas semánticas (HTML5).
  • Asegurar la accesibilidad y jerarquía de contenidos.
  • Organización de la arquitectura de ficheros.

Responsable CSS

  • Diseño visual y paleta de colores.
  • Maquetación responsiva (Flexbox y Grid).
  • Uso de variables CSS y estilos reutilizables.
  • Implementación de transiciones y animaciones.

Coordinador Visual y de Documentación

  • Revisión de la paleta de colores para para asegurar el contraste adecuado.
  • Supervisión del contenido y redacción de textos.
  • Elaboración de la memoria técnica del proyecto.
  • Gestión de capturas y documentación de diseño.
  • Revisión final de estándares y especificaciones.
