# Web Corporativa ASIR - Enunciado de Proyecto

Este repositorio contiene el código fuente de una página web corporativa moderna, diseñada como enunciado y ejemplo para el proyecto práctico de la asignatura **Lenguaje de Marcas (LND)** del ciclo **CFGS Administración de Sistemas Informáticos en Red**.

## Objetivo del Proyecto

El objetivo es que los alumnos trabajen en equipo para desarrollar una web estructurada, aplicando conocimientos de **HTML semántico** y **CSS3**, con un enfoque especial en la accesibilidad (WCAG) y el diseño responsivo.

## Estructura del Sitio

La web está organizada en las siguientes secciones:

*   **Inicio**: Presentación del proyecto y resumen ejecutivo.
*   **Requisitos**: Detalle de los requisitos técnicos necesarios para la evaluación.
*   **Roles**: Descripción de las responsabilidades de cada miembro del equipo (HTML, CSS y Documentación).
*   **Entregables**: Materiales finales que deben presentarse y orden recomendado de trabajo.
*   **Contacto**: Ejemplo de formulario funcional y datos de contacto.

## Tecnologías Utilizadas

*   **HTML5**: Estructura semántica completa.
*   **CSS3**: Maquetación moderna mediante Flexbox y Grid, uso de variables CSS y animaciones `@keyframes`.
*   **Diseño Responsivo**: Adaptado para una visualización óptima en móviles, tablets y escritorio.
*   **Accesibilidad**: Cumplimiento de estándares de contraste WCAG.

## Metodología y Roles

El proyecto está pensado para realizarse en equipos de 3 personas con los siguientes roles:
1.  **Responsable de Estructura (HTML)**.
2.  **Responsable de Estilo (CSS)**.
3.  **Responsable de Documentación y QA**.

## 📦 Cómo visualizar el proyecto

Para ver la web en funcionamiento:
1.  Clona el repositorio o descarga el archivo ZIP.
2.  Abre el archivo `index.html` en cualquier navegador moderno.
